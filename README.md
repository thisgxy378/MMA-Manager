# MMA Manager

A work-in-progress MMA promotion management game.

## Current prototype

- Choose to manage UFC, PFL, ONE, or RIZIN.
- Scout fictional prospects from regional and grassroots circuits, including Eternal MMA, Streetbeefs, Cage Warriors, LFA, OKTAGON, KSW, and BRAVE CF.
- Negotiate fighter contracts, book events, simulate results, and manage finances.
- AI promotions recruit and regional organisations run simulated bouts.

**Play the management alpha:** Open `management/index.html` in your browser.

**3D experiment:** Open `simulation/fight-simulator-v2.6.html` in a browser with internet access to load Three.js. The 3D simulator is on hold while management gameplay is developed.

## Game saves vs GitHub

The management prototype stores career state in browser `localStorage`. GitHub tracks **source-code changes**, not automatic career-game saves. Browser data may not transfer between devices or between local files and GitHub Pages. Back up your browser data before changing deployment URLs or clearing browser storage. Export/import saves and cloud syncing are future development goals.

## Development roadmap

1. Stronger contract system (negotiations, renewals, exclusivity, competing offers).
2. Roster, scouting, development and multiple AI promotion ecosystems.
3. Full fight cards, rankings, championship belts and scheduling.
4. More detailed finances and historical tracking.
5. Integrate the 3D autonomous fight simulator.
6. Stable versioned save/export format and, later, optional account-based cloud saves.

## Disclaimer

Independent fan-game prototype, unaffiliated with UFC, PFL, ONE, RIZIN, or the regional organisations named above. Fighters and financial data in the prototype are fictional/illustrative.
